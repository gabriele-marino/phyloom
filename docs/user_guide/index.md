# 📖 User guide

Phyloom offers two flexible ways to build and run simulations:

* **YAML configuration:** Define models declaratively for fast, reproducible experiment setups.
* **Python API:** Programmatically compose complex evolutionary dynamics, custom events, and scheduler behaviors.
